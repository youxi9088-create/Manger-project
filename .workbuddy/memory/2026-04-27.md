### 设计决策
- 采用 **computed_status 模式**：后端在返回需求数据时，根据需求内容和关联 dev_tasks 实时计算状态，附加 `computed_status` 字段
- 不修改 DB schema（无需 migration），保持原有 `status` 字段用于 AI 操作的硬写入

### 状态流转逻辑
| 条件 | computed_status | 前端标签 |
|------|----------------|---------|
| 无 raw_input、无 ai_analysis | `pending` | 待开始 |
| 有 raw_input、无 ai_analysis | `draft` | 草稿 |
| 有 ai_analysis、无 dev_tasks | `analyzed` | 已分析 |
| 有 dev_tasks、全部 todo | `tasked` | 已拆解 |
| 有 dev_tasks、部分 in_progress/testing | `in_progress` | 开发中 |
| 有 dev_tasks、全部 done | `done` | 已完成 |
